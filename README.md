# فیت‌میت — اپ وب موبایلی برنامهٔ تمرینی

اپ تک‌صفحه‌ای، فارسی و راست‌چین برای اجرای برنامهٔ بدنسازی در باشگاه.
بدون سرور، بدون حساب کاربری و بدون هیچ وابستگی؛ همهٔ داده‌ها در `localStorage` مرورگر می‌ماند.

## امکانات

- **فرم حرکت با نمایش متحرک** — کنار هر حرکت یک تصویر متحرک از الگوی حرکتی (ساخته‌شده در خود اپ با SVG، بدون فایل GIF و بدون اینترنت) به‌همراه دستور گام‌به‌گام اجرا، تنفس، خطاهای رایج و نکتهٔ ایمنی — برگرفته از منابع مرجع (NSCA، ACSM، ACE، ExRx). اگر فایل برنامه `media.gif` بدهد، همان گیف نمایش داده می‌شود.
- **نقشهٔ عضلات** — برای هر حرکت مشخص می‌کند اگر **درست** اجرا شود فشار روی کدام عضله می‌آید: بدنِ جلو و پشت با ناحیه‌های رنگ‌شده، به‌علاوهٔ سهم تقریبی هر عضله.
- **سوپرست در یک صفحه** — همهٔ حرکات یک دور کنار هم دیده می‌شوند، با ترتیب اجرا، استراحت بین حرکات و علامت‌گذاری اینکه الان کدام حرکت است.
- **نوار زمان** — ساعت شروع، زمان سپری‌شده و ساعت تخمینی پایان تمرین، همیشه بالای صفحه.
- **تمرین دونفره روی یک گوشی** — نوبت هر ورزشکار مشخص است و استراحت هرکس با ست نفر دیگر هماهنگ می‌شود تا وقت باشگاه هدر نرود. رکورد و «آخرین بار» هر نفر جدا نگه داشته می‌شود.
- **جایگزینی و جابه‌جایی حرکت** — وقتی دستگاه اشغال است، جایگزین هم‌الگو با توضیح اینکه چرا امن است و وزنهٔ پیشنهادی؛ یا فقط ترتیب را عوض کن بدون دست‌زدن به حجم و استراحت.
- **نقشهٔ کل برنامه در حین تمرین** — با یک دکمه، کل جلسه با وضعیت انجام‌شده/جاری/مانده و امکان پرش به هر حرکت.
- **توصیهٔ روزانهٔ پزشکی و غذایی** — یک توصیهٔ همسو با تمرین امروز، یک نکتهٔ تغذیه و یک نکتهٔ ریکاوری، هرکدام با ذکر منبع.
- **تم روشن/تیره/خودکار** — در تنظیمات.
- **بارگذاری برنامه از فایل JSON** — انتخاب فایل، کشیدن‌ورهاکردن یا چسباندن متن. خطاها با پیام فارسی و مسیر دقیق فیلد گزارش می‌شوند.
- **ویرایشگر داخلی** — ساخت و ویرایش برنامه بدون فایل، به‌همراه تب «JSON خام» با اعتبارسنجی زنده.
- **نمای جدولی خلاصه** — هر چیزی که تکرار می‌شود ادغام می‌شود: ست‌های یکسان در یک ردیف، پارامترهای مشترک یک‌بار در هدر بلوک، و بلوک‌های تکی پشت‌سرهم در یک جدول.
- **مود باشگاه** — تایمر استراحت با صدا و ویبره، ثبت وزنه/تکرار، ماشین‌حساب صفحات میله، «آخرین بار» و رکورد شخصی، شمارندهٔ تمپو، ست اضافه، رد کردن حرکت، و روشن ماندن صفحه.
- **انواع حرکت** — قدرتی تکراری، زمانی (پلانک و کشش)، و هوازی با مدت/مسافت/سرعت/شیب/ضربان و حالت اینتروال.
- **تکنیک‌های شدت** — دراپ‌ست، رست‌پاز و کلاستر، با راهنمای مرحله‌ای در مود باشگاه.
- **دوره‌بندی چندهفته‌ای** — روزها یک‌بار تعریف می‌شوند و هفته‌ها با قانون پیشرفت (خطی، دوگانه، درصدی از ۱RM) و هفتهٔ دیلود محاسبه می‌شوند؛ اختلاف با هفتهٔ قبل به‌صورت دلتا نمایش داده می‌شود.
- **PWA آفلاین** — قابل نصب روی هوم‌اسکرین و کارکرد کامل بدون اینترنت.
- **پشتیبان‌گیری/بازیابی** — خروجی و ورودی JSON از کل برنامه‌ها، تاریخچه و تنظیمات.

## اجرا

سرویس‌ورکر و ماژول‌های ES نیاز به سرو شدن روی HTTP دارند (با `file://` کار نمی‌کنند):

```bash
python3 -m http.server 8000
# سپس http://localhost:8000 را روی موبایل یا حالت موبایل DevTools باز کنید
```

برای انتشار، کل پوشه را روی هر هاست استاتیک (GitHub Pages، Netlify، …) بگذارید.

## اسکیمای فایل برنامه (`fitmeat/v1`)

اصل طراحی: **هیچ چیزی دوبار نوشته نمی‌شود.** هر پارامتر در بالاترین سطح ممکن تعریف و فقط در صورت تفاوت override می‌شود.
زنجیرهٔ ارث‌بری برای `rest`، `tempo`، `rpe`، `rir` و `unit`:

```
set → exercise → block → day.defaults → program.defaults
```

```jsonc
{
  "schema": "fitmeat/v1",
  "name": "برنامهٔ من",
  "note": "توضیح اختیاری",
  "defaults": { "rest": 90, "tempo": "3-1-1-0", "unit": "kg" },

  "weeks": {
    "count": 4,
    "progression": { "type": "double", "increment": 2.5, "percents": [70, 75, 80, 85] },
    "deload": { "week": 4, "volume": 0.6, "intensity": 0.9 }
  },

  "days": [{
    "id": "push",
    "name": "روز ۱ — بالاتنه",
    "note": "اختیاری",
    "defaults": { "rest": 120 },
    "blocks": [{
      "type": "single",              // single | superset | circuit
      "rounds": 4,                   // تعداد ست (تکی) یا تعداد دور (سوپرست/سیرکویت)
      "rest": 90,                    // استراحت بعد از هر ست/دور — ثانیه
      "restBetweenExercises": 15,    // فقط سوپرست/سیرکویت
      "exercises": [{
        "name": "پرس سینه هالتر",
        "mode": "reps",              // reps | time | cardio
        "muscle": "سینه",
        "equipment": "هالتر",
        "reps": "8-10",              // عدد، بازه، یا "AMRAP"
        "weight": 60,
        "tempo": "3-1-1-0",
        "rpe": 8,                    // یا "rir": 2
        "cue": "کتف جمع، آرنج ۴۵ درجه",
        "alternatives": ["پرس سینه دمبل"],
        "media": { "gif": "https://…", "image": "https://…", "video": "https://…" },
        "technique": { "type": "drop", "drops": [{ "reduce": "20%", "reps": "AMRAP" }] },
        "sets": [                    // اختیاری — فقط وقتی ست‌ها ناهمگون‌اند (هرمی)
          { "reps": 12, "weight": 40 },
          { "reps": 10, "weight": 50 }
        ]
      }]
    }]
  }]
}
```

### انواع حرکت

| `mode` | فیلدهای کلیدی | کاربرد |
|---|---|---|
| `reps` | `reps`، `weight` یا `intensity`+`oneRM` | حرکات قدرتی و شکمی تکراری |
| `time` | `duration` (ثانیه) | پلانک، کشش، نگه‌داشتن ایزومتریک |
| `cardio` | `duration`، `distance`، `speed`، `incline`، `hrZone`، `intervals` | تردمیل، دوچرخه، اینتروال |

اینتروال هوازی:

```json
"intervals": { "rounds": 6, "work": { "duration": 60, "speed": 12 },
               "recover": { "duration": 120, "speed": 7 } }
```

### تکنیک‌های شدت

```json
{ "type": "drop", "drops": [{ "reduce": "25%", "reps": "AMRAP" }] }
{ "type": "restPause", "pauses": 2, "rest": 15 }
{ "type": "cluster", "clusters": 4, "repsPer": 2, "rest": 20 }
```

### قوانین پیشرفت

| `type` | رفتار |
|---|---|
| `none` | همهٔ هفته‌ها یکسان |
| `linear` | هر هفته `increment` به وزنه اضافه می‌شود |
| `double` | اول تکرار در بازه بالا می‌رود، بعد وزنه یک پله زیاد و تکرار به ابتدای بازه برمی‌گردد |
| `percent` | وزنه از `percents[هفته]` × `oneRM` حساب می‌شود |

هفتهٔ دیلود با `volume` (ضریب تعداد ست) و `intensity` (ضریب وزنه) اعمال می‌شود.
وزنهٔ حرکات هالتری به نزدیک‌ترین ترکیب ممکن با صفحات تعریف‌شده در تنظیمات گرد می‌شود.

## فرم حرکت، عضلات و منابع

اپ برای هر حرکت سه چیز نشان می‌دهد:

1. **نمایش متحرک الگوی حرکتی** — فیگوری که خودِ اپ با SVG می‌سازد. سایهٔ کم‌رنگ، انتهای دامنهٔ حرکت است، پس حتی در یک نگاهِ ثابت هم دامنه معلوم است. تابع `prefers-reduced-motion` است.
   اگر فایل برنامه برای حرکتی `media.gif` یا `media.image` بدهد، همان تصویر جای فیگور می‌نشیند.
2. **دستور اجرا** — آماده‌سازی، اجرا، تنفس، خطاهای رایج و نکتهٔ ایمنی.
3. **نقشهٔ عضلات** — کدام عضله چقدر از بار را می‌گیرد، روی بدن و به‌صورت نمودار میله‌ای.

منابع محتوا:

- NSCA — *Essentials of Strength Training and Conditioning*, 4th ed.
- ACSM — *Guidelines for Exercise Testing and Prescription*, 11th ed.
- ACE — Exercise Library
- Kendall et al. — *Muscles: Testing and Function*, 5th ed.
- ExRx.net — Exercise Directory

**دربارهٔ درصدها:** سهم عضلات تخمینی است و از کارکرد مفصلی و جمع‌بندی مطالعات EMG در منابع بالا می‌آید،
نه اندازه‌گیری روی بدن شما. برای فهمیدن «کجا باید فشار را حس کنم» مفید است، نه برای محاسبهٔ دقیق حجم تمرین.

حرکاتی که در دانش‌نامه نیستند از روی نام‌شان به نزدیک‌ترین الگوی حرکتی نگاشت می‌شوند و اپ این را
صریح اعلام می‌کند؛ برای فرم دقیق، توضیح را در فیلد `cue` همان حرکت بنویسید.

## تمرین دونفره

در تنظیمات، «حالت دونفره» را روشن کنید و نام دو ورزشکار را بنویسید. بعد از آن در مود باشگاه:

- بالای صفحه مشخص است **الان نوبت کیست** (رنگ + حرف اول نام + برچسب متنی، پس فقط به رنگ وابسته نیست).
- ترتیب اجرا در هر ست: هر حرکت را هر دو نفر می‌زنند، بعد حرکت بعد.
- **استراحت با ست نفر دیگر هماهنگ می‌شود:** تا وقتی نفر دوم مشغول است، استراحت نفر اول در حال گذشتن است.
  صفحهٔ استراحت فقط وقتی می‌آید که هنوز به استراحتِ لازم نرسیده باشید، و فقط برای همان مقدارِ باقی‌مانده.
- «آخرین بار» و رکورد شخصی برای هر نفر جداگانه نگه داشته می‌شود.

## توصیهٔ روزانه

هر روز تمرین با سه توصیه شروع می‌شود: یک نکتهٔ پزشکی همسو با نوع تمرین آن روز، یک نکتهٔ تغذیه و یک
نکتهٔ ریکاوری — هرکدام با ذکر منبع (ACSM، ISSN، WHO، NSCA). این‌ها آموزش عمومی‌اند و
**جایگزین معاینه و نسخهٔ پزشک نیستند**؛ همین هشدار زیر خود کارت هم نوشته شده است.
از تنظیمات می‌توان این بخش را خاموش کرد.

## برند و تم

جهت‌گیری بصری، پالت و دلیل هر انتخاب در [`BRAND.md`](BRAND.md) آمده است.
سه حالت تم — خودکار، روشن، تیره — در **تنظیمات → ظاهر**. هیچ رنگی در ویوها هاردکد نشده؛
همه از توکن‌های `assets/styles.css` می‌آید.

## حریم خصوصی

هیچ داده‌ای از دستگاه خارج نمی‌شود. پاک‌کردن داده‌های سایت در مرورگر، برنامه‌ها و تاریخچه را حذف می‌کند —
پیش از آن از بخش تنظیمات خروجی پشتیبان بگیرید.
